远程协助 · 开启 SSH

让协助你的人（和 TA 的 AI 助手）通过 SSH 远程排查这台电脑。只允许 TA 的密钥登录，同时关闭 SSH 的密码登录；4 小时后自动关闭，也可以随时一键关闭。

开启

  1. 点右边「复制」。
  2. 按 Win + R，粘贴。
  3. 按 Ctrl + Shift + Enter（以管理员身份运行），弹窗点「是」。
  4. 窗口出现绿色 Remote Assist SSH is ON，把 user、host、fingerprint 三行发给协助你的人。

第一次会安装 Windows 自带的 OpenSSH 服务，可能要几分钟。

不在同一个网络时（跨网络）

用这条代替上面的开启命令，操作方式相同。它先开启 SSH，再通过 Pinggy 打一条加密隧道。窗口出现绿色 Remote Assist tunnel is ON 后，把 user、host、fingerprint 三行发给协助你的人。这个窗口要一直开着，关掉窗口隧道就断开。

隧道地址最长保持 60 分钟，断开后会自动重连，但地址会变，需要重新发一次。即使走隧道，也只有协助者的密钥能登录。

用完后关闭

同样 Win + R → 粘贴 → Ctrl + Shift + Enter。会删除密钥、恢复密码登录设置、停止并禁用 SSH 服务、移除防火墙规则和自动关闭任务。

开启

  1. 点右边「复制」。
  2. 按 ⌘ + 空格，输入「终端」回车打开。
  3. 粘贴后回车，按提示输入开机密码（输入时不显示，正常）。
  4. 出现 Remote Assist SSH is ON，把 user、host、fingerprint 三行发给协助你的人。

如果提示没能启动，打开「系统设置 → 通用 → 共享」，手动打开「远程登录」后再运行一次。

不在同一个网络时（跨网络）

用这条代替上面的开启命令。它先开启 SSH，再通过 Pinggy 打一条加密隧道。出现 Remote Assist tunnel is ON 后，把 user、host、fingerprint 三行发给协助你的人。终端窗口要一直开着，按 Ctrl + C 或关掉窗口隧道就断开。

隧道地址最长保持 60 分钟，断开后会自动重连，但地址会变，需要重新发一次。即使走隧道，也只有协助者的密钥能登录。

用完后关闭

在终端粘贴回车，会删除密钥、恢复密码登录设置、关闭「远程登录」和自动关闭任务。
